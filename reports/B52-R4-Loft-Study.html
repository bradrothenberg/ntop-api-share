IoU = shared silhouette area / combined silhouette area. All 4,752 final guide control points match the native API export. The model silhouettes include the native crown, keel, and width clips. Full source contours remain in the score, including gear-recess and tail-fairing differences.

The final integration uses 4,097 longitudinal samples and 513 transverse samples. Doubling both sampling densities changed the scores by at most 0.000815 percentage points. No per-view rescaling or post-fit registration is used. Window annotations are excluded from the skin metric.

Viewport limitation

The prototype voxel preview shows a small gap below the aft crown in front view. A native field probe confirms solid material there: -0.014727 m at (8.2, 0, 0.449) m. The continuous geometric projection has no gap. The headline scores therefore use native spline geometry, not the coarse viewport mask.

03 / REFERENCE AND DELIVERYUse the B-52F benchmark consistently.

This revision uses the public FlightGear B-52F artist model, as you requested. It replaces the conflicting B-52H drawing as the 99% benchmark. R2 and R3 use that earlier drawing, so their percentages are not directly comparable.

The source authors state that the model is not an authentic representation. These percentages therefore describe agreement with this public model. They do not establish 99% accuracy to a production B-52 airframe.
