Evidence boundary

The runner executes fresh numerical tests and checks existing mesh receipts against frozen hashes. It does not rerun the complete mesh screen, perform CFD, or test hardware.

The mission is an expendable search-and-rescue drone with 10800 seconds of continuous duty and total service life. Casting and sheet metal are preferred; compressor and turbine printing is permitted for assessment.

The default performance model reproduces its normalized design point by construction. It cannot verify installed thrust. The 100,000 rpm, 2.9 pressure ratio, and 1100 K study limits remain unqualified inputs.

C5 adopts approximately 110 kg total takeoff mass and an aircraft L/D target of approximately 12. At 20 lbf, the exact level-flight L/D threshold is about 12.13. At exactly L/D 12, the nominal aircraft needs about 20.21 lbf or a mass reduction to about 108.86 kg. Actual drag and thrust margin require verification.

04Run and interpret the tests

Use the unit-only command for software regression. The full requirement command exits 0 when software tests pass and no inspected criterion fails. This is not a manufacturing release. The release command exits 2 while any requirement remains open.

The requirements JUnit file reports open criteria as skipped, with reasons. Skipped criteria block release. The SysML parser receipt records syntax, semantic, and negative-control results.

Hardware criteria need a reviewed evidence adapter when real data arrive. Filling a decision value or editing a status string cannot establish compliance. Do not refresh evidence hashes to hide a regression.
