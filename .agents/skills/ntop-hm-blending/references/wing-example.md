# Worked mid, upper, and lower wing example

This is an illustrative analytic wing and fuselage, not a certified aircraft or
a NACA reconstruction. Dimensions below were selected for the demonstration.
The scalar implementation is [wing_example.py](../scripts/wing_example.py).

## Geometry and settings

Coordinates: x runs along the fuselage, y spans the wing, and z points upward.
All scalar helper inputs and outputs use millimetres.

| Setting | Value |
|---|---:|
| Fuselage radius R | 17.5 mm |
| Fuselage half length A | 92.5 mm |
| Root chord | 70 mm |
| Half span | 110 mm |
| Tip/root chord parameter | 0.55 |
| Thickness/chord parameter | 0.12 |
| Sweep | 20 degrees |
| Sweep center smoothing | 2 mm |
| Maximum thickness chord fraction | 0.3 |
| Wing vertical offsets | 0, +10.5, -10.5 mm |
| Candidate field widths | 4 and 9 mm |
| Conventional comparison width | 6.5 mm, not optimized |
| Aft taper interval | x=25 to 65 mm |
| Anchor transverse scale | 8 mm |
| HM reference length and p | 10 mm and -4 |
| Log weights | 0 and 0.75*S_aft |

The fuselage field is

~~~text
F = ((x/A)^8 + (y^2+z^2)/R^2 - 1)*R/2
~~~

Its centerline crown is c(x)=R*sqrt(1-(x/A)^8) where the radicand is positive.
For finite evaluation only, the implementation floors the radicand at 1e-10.
The substituted anchor fuselage value is zero in the example. Outside the true
crown domain, that substitution no longer describes a real surface. Revalidate
end regions and do not copy this expedient into a general imported-body blend.

The wing uses a smooth span coordinate, rational chord variation, an analytic
thickness function, and a spanwise closure term. Read the short scalar source for
the exact equations before reproducing them in nTop. The positive exponential
field rescaling preserves the wing zero set and improves its behavior far from
the chord. It still changes how the wing participates in a blend.

## What removed the shoulder

An earlier construction ramped blend width across abs(y)=6 to 12 mm. It protected
the centerline but created long shoulders beside that band. The revised version
removed the narrow width gate and anchored each candidate with a broad Gaussian
correction. The aft taper remained.

At x=-5 mm, sampled maximum absolute transverse normal curvature fell from
0.56259 to 0.03776 per mm. At x=10 mm it fell from 0.46814 to 0.04548 per mm.
Those before/after changes included the new anchor construction. They are not an
isolated measurement of the paper operator. A tight aft-root feature remained.

## Controlled comparison

A later comparison held the geometry, support, anchors, and camera fixed.
It evaluated a single 6.5 mm C2 union, a linear average of the two corrected
candidates using the HM effective weights, and Eq.20.

Maximum sampled vertical differences from HM across x=-5,10,25,40 mm,
y=0..30 mm, with 0.05 mm spacing:

| Position | Single C2 versus HM | Matched linear versus HM |
|---|---:|---:|
| Mid | 0.1748 mm | 0.0638 mm |
| Upper | 0.0993 mm | 0.0363 mm |
| Lower | 0.0993 mm | 0.0363 mm |

These are vertical section differences, not full-surface closest distances.
The second column of differences isolates changing the averaging operator.

Peak absolute surface-normal curvature over y=3..25 mm:

| Position | Section x | Single C2 | Linear | HM |
|---|---:|---:|---:|---:|
| Mid | -5 mm | 0.1531/mm | 0.1802/mm | 0.1670/mm |
| Mid | 40 mm | 0.5242/mm | 0.6290/mm | 0.6153/mm |
| Upper/lower | -5 mm | 0.0487/mm | 0.0388/mm | 0.0378/mm |
| Upper/lower | 40 mm | 0.1137/mm | 0.1433/mm | 0.1393/mm |

The single C2 construction had lower peak curvature on all four sampled mid-wing
sections. HM lowered the forward upper/lower peak relative to that baseline.
The conventional construction had a lower aft peak. Upper and lower results
match because these primitives are reflected copies, not because high-wing and
low-wing aircraft have equivalent aerodynamics.

All nine cases passed sampled crown/keel extent and surface-gradient checks.
This was not a global no-bump proof. Source trimming is permitted in this
example; a previous anchored-case study measured about 1.01 micrometres of
maximum inward source-normal line retreat in its selected samples.

## Portable evidence

[native_samples.json](../assets/native_samples.json) contains the 270 captured
native values, coordinates, normalized units, source notebook hashes, and the
measured runtime. No native values are generated by the portable checker.

Run from any working directory:

~~~powershell
uv run python "<skill>/scripts/check_blend.py"
~~~

This verifies algebraic invariants and the scalar formulas against those frozen
values. It does not rerun the historical surface, curvature, or rendering studies.
The maximum native/reference discrepancy in the original study was 4.2633e-14
in normalized field units. The checker uses a 1e-10 normalized numerical
tolerance, not an aerodynamic or manufacturing tolerance.

For a new model, repeat current-build native sampling, section and gradient
checks, source-retreat measurement, and native visual inspection. Require a
separate aerodynamic analysis before making performance claims.
