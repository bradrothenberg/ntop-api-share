# Recorded engineering-film workflow

The source landing-gear film used a separate Unlinked model and Omniverse Kit
110.1.5.386822. Its model, runtime, frames, fonts, and project scripts are not
included here. Locate authorized installations and verify their versions.

The reusable file contract separates the storyboard, scene preparation,
continuous frame capture, simulation-to-film clock, cameras, editing,
encoded-frame review, and final provenance receipt.

Use environment variables or explicit arguments for runtime and FFmpeg paths.
Use `uv run` with the intended interpreter for Python work. Obtain licensed
brand fonts separately. Do not assume another machine has the same installation.

The recorded edit removed FEA from the opening at normal speed. The later
slow replay, revision comparison, inspection, and closing shots stayed unchanged.
That required checking source frames and proving the unchanged tail after encoding.

Reuse the workflow, not its subject, loads, durations, revision count, stress
ranges, frame indices, GPU timings, or publication destination.
