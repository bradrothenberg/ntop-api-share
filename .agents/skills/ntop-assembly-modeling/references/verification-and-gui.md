# Verification and direct native GUI delivery

## Distinct evidence

| Check | What it establishes |
|---|---|
| Dependency closure | Every input needed by the output is included and resolves |
| Exact expression comparison | A refactor preserves functions, values, properties, and wiring |
| Source comparison | The modeled part agrees with an independent geometry reference |
| Native control checks | Values propagate through saved custom calls and placements |
| Native render | The application rendered the selected visible geometry |
| Scoped GUI inspection | Separate bodies, colors, controls, and collapsed states are usable |
| Controlled timing | A measured cost under the stated build, hardware, visibility, and caches |

Compare complete default and symbolic output expressions after modularization. Symbolic checks must retain input order and types, so a constant default cannot hide a disconnected control. A graph match does not make a flawed source reconstruction accurate.

For source remodeling, validate each family against the independent reference before validating placements. Use a defined overlap metric and sampled surface checks when appropriate. Keep local holes, walls, fillets, and contact checks separate from the global score.

Use nominal and changed control values to verify instance bounds and feature boundaries. Include a minimum or clamped case when the model defines one. Do not infer the whole supported range from one successful expanded model.

## Native presentation

Show one placed native body per intended assembly instance. Use a stable family palette and retain separate output variables. Hide construction and unplaced source families. A union may remain available for export or analysis, but should not conceal the selectable instance structure.

For the learned assembly, the latest requested presentation is 28 visible native bodies. Earlier mesh/grid views are historical alternatives. They do not override the current direct-native preference and are not the default for this skill.

Group controls, placed bodies, family definitions, and helpers into readable sections. Collapse authored descendants, promoted input cards, custom sections, and imported states after the final geometry save. Keep the root group open.

Recorded saved UI paths use `100_` for the root and descendants such as `100_0_0`, without a trailing underscore. Reuse actual saved paths and model indexes. Do not invent input-card or imported-model indexes. Use a measured repository helper or the native UI for the installed build.

Apply layout changes to a separate deliverable while retaining the API-saved source. Prove non-layout content equality and reopen the result. Never patch a file while nTop is saving it.

Exterior views can hide internal parts. Verify body count and visibility records separately, then inspect selected internal groups or an exploded view if needed. A good-looking closed exterior does not prove all instances exist.

An approved snapshot preview requires a verified source mesh, explicit refresh instructions, exact retained native output/input contracts, and native readback. Inspect imported topology independently of image quality. Do not silently suppress import warnings or replace an accepted native body during display experiments.

## Timing and delivery

Compare main-tree rows, all native dependency records, unique family definitions, and placed instances with their scopes stated. Shared definitions and instance-weighted feature uses are different counts.

Keep build, machine, threads, inputs, visibility, display fidelity, and cache policy equal for a speed comparison. Distinguish cold and warm loads. Measure a control edit through completed native evaluation and refreshed visible geometry for a live GUI update result.

CLI wall time includes startup and notebook loading. Launch-to-screenshot time is not a live GUI update benchmark. A timeout is incomplete evidence; check the owned process and completion record before retrying. A smaller notebook tree alone does not prove a speedup.

Keep local artifacts and relative dependencies together. Before public copying, inspect native metadata, literal paths, binary strings, and embedded content. The bundled pilot supplies source only; it does not distribute native binaries or a full application-specific assembly.
