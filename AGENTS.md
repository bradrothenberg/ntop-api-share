## Torx, 17 September 2026

[demos/torx](demos/torx/README.md) ports a seven-block custom assembly from a sibling source project onto this repository's recipe harness. It is the case the node-by-node transport cannot express at all: build 42926 has no live method that creates a custom block, so the definitions can only arrive through `import_recipe`. Do not describe the demo as if it had a live-API mirror backend.
The port is checked against nTop's own recorded recipe for the same graph, not against itself. Keep `check_recipe.py` at 8 of 8 after any graph edit.
The port covers the thirteen-input public block. The released V2 compact assembly exposes eighteen, adding Placement mode, Reference Body, Tilt X, Tilt Y and Flush, and returns a paired screw and mould container read through two extractor blocks. Do not present the ported block as the released screw.
Findings F9 to F13 in [FINDINGS_RC42926_LIVE.md](FINDINGS_RC42926_LIVE.md) come from that work. F13 matters for any notebook with an external input: a `file_path` value is container state, not recipe data, so `import_recipe` reproduces the graph and silently drops the file. F11 changes how a slice index converts to a coordinate on this build; read a raster with the law measured on the build in hand, not the recorded one. F12 separates a measured proportionality from an inference about its cause; keep them separate.
